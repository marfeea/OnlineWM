# OnlineWM 世界模型研究纲领

> 文档版本：v2.1
> 基线日期：2026-07-25
> 文档定位：OnlineWM 项目的总世界模型研究纲领
> 使用方式：规定长期研究目标、研究问题、阶段关系和评价原则，不规定代码结构、接口、命令或具体实现方案。

## 1. 纲领定位

本纲领用于回答四个宏观问题：

1. OnlineWM 为什么研究世界模型。
2. 项目希望逐步解决哪些科学问题。
3. 各研究阶段之间如何递进。
4. 什么证据能够支持阶段性研究结论。

本纲领不是开发任务清单，不承担以下职责：

- 规定具体算法实现；
- 规定软件模块、类、函数或数据结构；
- 规定环境接口、动作空间或观测字段；
- 提供安装、训练或测试命令；
- 给出固定训练预算、超参数或硬件配置；
- 追踪具体代码任务的完成状态。

具体实施内容应由阶段性开发文档承担。当前阶段的执行文档是：

- `doc/R2Dreamer单臂AUBO训练与真机部署开发路线.md`

## 2. 总体研究愿景

OnlineWM 希望形成一个面向机器人控制的世界模型研究体系，使智能体能够：

1. 从视觉、本体感知和交互历史中形成紧凑、可预测、与任务相关的潜在状态。
2. 学习动作条件下的环境演化规律，并表达预测中的不确定性。
3. 在学习到的潜空间中进行未来推演，支持策略学习、规划和控制。
4. 从标准单智能体任务逐步扩展到接触丰富、长时序和多机器人协作任务。
5. 建立从仿真研究走向真实系统验证的证据链。

项目不把“训练成功”本身视为最终目标，而把世界模型是否学到可解释、可迁移、可用于决策的动态结构作为核心研究对象。

## 3. 核心研究问题

### RQ1：任务相关表征

如何从高维视觉和多模态观测中提取对控制有用的信息，同时抑制与任务无关的背景和冗余？

重点关注：

- 小而关键的视觉目标；
- 部分可观测条件下的历史信息整合；
- 表征压缩与信息保真的平衡；
- 状态表征对任务变化和视觉扰动的稳健性。

### RQ2：学习式动力学

如何在潜空间中学习动作条件的状态转移，使模型能够预测机器人、物体、接触和任务进度的演化？

重点关注：

- 随机性与多模态未来；
- 长时序误差累积；
- 接触切换和非平滑动力学；
- 模型不确定性与分布外状态；
- 学习式隐式动力学与物理先验的关系。

### RQ3：世界模型驱动的决策

如何将预测模型转化为可靠的控制能力，而不是仅获得较低的预测损失？

重点关注：

- 潜空间想象与真实环境行为的一致性；
- 短期回报与长期任务目标的平衡；
- 奖励稀疏、延迟反馈和探索；
- 模型误差对策略优化的影响；
- 决策性能与模型质量之间的因果关系。

### RQ4：机器人任务中的接触与约束

如何使世界模型处理精细操作中常见的接触、摩擦、约束和执行器误差？

重点关注：

- 接触事件是否能够被潜状态识别和预测；
- 视觉、本体感知和力觉之间的互补关系；
- 显式物理结构与数据驱动模型的融合；
- 安全约束和不可逆失败的处理。

### RQ5：多臂与多机器人协作

如何将单智能体世界模型扩展到具有耦合动力学、共享任务目标和多主体决策的协作系统？

重点关注：

- 联合状态与局部状态的表示；
- 集中式、分布式和分层世界模型；
- 协同动作、角色分工和通信；
- 闭链约束、接触力和内力分配；
- 多主体信用分配与可扩展性。

该问题属于未来研究主线，不进入当前阶段的开发范围。

### RQ6：泛化、迁移与真实系统

如何判断世界模型学到的是可迁移的动态规律，而不是特定仿真环境中的统计捷径？

重点关注：

- 跨场景、跨对象和跨任务泛化；
- 视觉域偏移和动态参数变化；
- 少量真实数据适配；
- 不确定性感知与安全退化；
- sim-to-real 的可验证证据。

## 4. 研究主线

项目长期围绕六条相互关联的主线推进。

| 主线 | 研究对象 | 核心判断 |
|---|---|---|
| 表征学习 | 视觉、多模态观测、潜状态 | 是否保留控制相关信息并抑制冗余 |
| 动力学建模 | 动作条件的潜状态转移 | 是否能够预测可控、长期和不确定的未来 |
| 决策与控制 | 想象轨迹、价值与策略 | 模型是否真正改善决策质量与样本效率 |
| 机器人交互 | 接触、摩擦、约束和执行误差 | 模型能否处理非平滑、接触丰富的操作 |
| 协作建模 | 双臂、多臂和多机器人 | 模型能否表达耦合关系、通信和协同决策 |
| 泛化与迁移 | 新对象、新任务和真实系统 | 能力是否超出训练分布并保持安全性 |

这些主线不是互斥阶段。每个具体研究项目应明确自己主要回答哪一条主线，并说明对其他主线的影响。

## 5. 宏观发展阶段

### 阶段 A：知识基础与可复现基线

目标：

- 建立世界模型、模型式强化学习和机器人动力学建模的文献体系。
- 理解代表性方法的假设、贡献、局限和评价协议。
- 获得能够重复运行的公开基线，为后续研究提供可信参照。

阶段产出：

- 结构化论文库；
- 方法、benchmark 和机器人平台对比材料；
- 可复现基线报告；
- 研究问题与证据边界说明。

### 阶段 B：视觉世界模型与在线控制

目标：

- 研究视觉表征、潜在动力学和在线策略学习之间的关系。
- 验证模型能否从像素输入形成支持控制的状态。
- 建立训练稳定性、样本效率和计算成本的评价方法。

R2-Dreamer 官方 IsaacLab 训练和 AUBO 单臂策略训练的算法基础属于本阶段。

阶段产出：

- 稳定的视觉世界模型基线；
- 表征质量、控制性能和资源消耗的联合分析；
- 对失败模式和适用边界的解释。

### 阶段 C：本地机器人任务迁移

目标：

- 将经过验证的世界模型迁移到具有机器人学意义的本地任务。
- 研究控制频率、接触复杂度、奖励稀疏性和视觉设计对模型学习的影响。
- 明确标准 benchmark 结果与本地机器人任务结果之间的结论边界。

该阶段是当前研究主线的一部分，在阶段 B 的官方链路形成稳定证据后继续推进。

阶段产出：

- 本地机器人任务研究协议；
- 任务迁移与失败分析；
- 面向机器人交互的世界模型评价体系。

### 阶段 D：接触与结构化动力学

目标：

- 研究世界模型对接触事件、摩擦、约束和多模态动力学的表达能力。
- 探索学习式动力学与解析模型、物理先验或约束优化的结合。
- 提高模型在精细操作和分布变化下的可靠性。

阶段产出：

- 接触丰富任务的系统实验；
- 隐式与混合动力学建模比较；
- 不确定性、失败检测与安全边界分析。

### 阶段 E：双臂与多机器人协作

目标：

- 研究多主体世界模型的表示、预测与决策机制。
- 处理双臂耦合、闭链、内力、通信和角色分工。
- 建立能够区分单臂能力与协作能力的评价协议。

本阶段属于未来计划，不作为当前研发里程碑。

阶段产出：

- 多臂协作世界模型问题定义；
- 集中式、分布式或分层建模研究；
- 双臂/多机器人 benchmark 与评价指标；
- 协作失败类型和结论边界。

### 阶段 F：真实系统与持续学习

目标：

- 评估仿真中学习到的表征和动力学能否迁移至真实系统。
- 研究少量真实数据适配、在线更新、安全约束和模型漂移。
- 形成可审计、可退化和可持续学习的真实机器人世界模型。

阶段产出：

- sim-to-real 证据；
- 真实系统风险与安全协议；
- 持续学习和模型更新研究。

当前项目以完成 AUBO 单臂策略的受控真机部署作为阶段 F 的首个目标。持续在线学习不作为首次真机部署的必要条件。

## 6. 当前研究优先级

当前研究主线贯穿阶段 A、B、C，并以阶段 F 的单臂真机验证为目标：

1. 固化 R2-Dreamer 和 Isaac Lab 的公开基线。
2. 验证状态输入和视觉输入的官方训练链路。
3. 设计并实现本地 AUBO 单臂任务。
4. 在仿真中训练和评估 AUBO 单臂策略。
5. 建立 sim-to-real、真机安全和部署证据。
6. 在单台 AUBO 上完成受控策略验证。

以下内容当前暂缓：

- 双臂/多臂建模；
- 多智能体协作；
- 大规模算法对照与完整 benchmark 复现。

优先级变化必须经过阶段评审，并形成新的专项开发文档。

## 7. 研究评价框架

不同阶段的具体指标可以变化，但研究结论至少应从以下维度建立证据。

### 7.1 模型质量

- 潜状态是否具有预测性；
- 长时序预测是否稳定；
- 是否保留任务相关信息；
- 是否能表达不确定性和分布外状态；
- 模型错误是否能够被识别。

### 7.2 控制质量

- 任务回报与成功；
- 样本效率；
- 长时序决策能力；
- 稀疏奖励下的探索；
- 对扰动、参数变化和观测缺失的稳健性。

### 7.3 机器人学有效性

- 是否覆盖真实任务中的接触和约束；
- 是否能区分任务进展与视觉捷径；
- 是否能够解释典型失败；
- 是否具备向新对象、新任务和真实系统迁移的潜力。

### 7.4 计算与复现

- 训练成本和环境交互成本；
- 运行稳定性；
- 随机种子敏感性；
- 版本、配置和原始证据的可追溯性；
- 不同实现和硬件条件下的结论边界。

## 8. 研究证据等级

| 等级 | 含义 | 可支持的表述 |
|---|---|---|
| E0：概念 | 来自论文假设或研究构想，尚无本地实验 | 研究动机与待验证问题 |
| E1：链路 | 系统能够稳定运行，数据与训练闭环正确 | 工程可行性 |
| E2：任务 | 在明确任务和协议下获得重复结果 | 当前任务中的有效性 |
| E3：泛化 | 跨任务、跨场景或跨随机种子保持结果 | 有限范围的泛化能力 |
| E4：机器人 | 在接触丰富或真实机器人条件下验证 | 机器人学有效性 |
| E5：协作 | 在双臂/多机器人任务中验证协作机制 | 协作建模结论 |

不得用较低证据等级支持较高层级结论。例如，官方 Cartpole 视觉训练只能证明链路和标准任务有效性，不能证明双臂协作或真实机器人适用性。

## 9. 关键研究风险

### 9.1 表征与任务错配

较低的表征损失不一定意味着更好的控制；模型可能保留易预测但与任务无关的信息。

### 9.2 潜空间动力学缺乏物理解释

RSSM 能够学习隐式状态转移，但不直接给出接触力、摩擦、内力和安全约束。

### 9.3 benchmark 外推过度

标准视觉控制结果不能直接外推到接触丰富、双臂协作或真实机器人系统。

### 9.4 计算成本掩盖算法贡献

环境吞吐、渲染、模型规模和训练比率可能对结果产生与算法设计同等重要的影响。

### 9.5 复现与版本漂移

论文、官方代码、依赖和仿真器持续变化；任何结论都必须绑定版本、配置和运行证据。

## 11. 阶段评审原则

每个宏观阶段结束时应回答：

1. 本阶段原计划回答的研究问题是什么。
2. 获得了哪一级证据。
3. 哪些结论被支持，哪些仍不能支持。
4. 主要失败来自算法、环境、数据还是评价协议。
5. 是否具备进入下一阶段的研究条件。
6. 下一阶段是否需要新的 benchmark、传感器、模型假设或安全约束。

只有当阶段评审确认研究价值和证据充分时，才创建下一阶段的技术开发文档。
